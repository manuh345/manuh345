## > featured_projects

### 🛰️ Geoconnect
Real-time, location-aware attendance and site verification system built for a cleaning services company as my final-year project.
- GPS-based check-in/check-out with live map tracking (Socket.io)
- Role-based access control (Admin / Supervisor / Cleaner)
- Device-sharing fraud detection, CSV exports, shift scheduling
- **Stack:** React Native (Expo) · Node.js · Express · Socket.io · React/Vite dashboard

### 📈 Flax Unified Trading System (QTS-100)
Algorithmic trading infrastructure for XAUUSD and EURUSD built around Smart Money Concepts (liquidity sweeps, BOS, CHoCH, Order Blocks, FVGs).
- MQL5 Expert Advisors and SMC structure scanners
- Node.js/Express + Firebase scoring engine with correlation guard and regime detection
- TradingView Pine Script v6 indicator with divergence detection and webhook alerts
- **Stack:** MQL5 · Node.js · Firebase Firestore · Pine Script · React

### 🌾 Limuru Farmers' Cooperative System
Grading and payroll management system for a farmers' cooperative, with full audit trail.
- Role-based access for admins, clerks, and farmers
- CSV export and mobile-friendly navigation
- **Stack:** PHP · MySQL · XAMPP
